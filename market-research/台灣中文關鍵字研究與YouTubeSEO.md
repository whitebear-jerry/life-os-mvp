# 台灣中文關鍵字研究與 YouTube SEO

## 0. 研究口徑與限制

v2 補洞版已加入兩種真實公開數據：

1. Google Trends：用 `pytrends` 抓台灣近 12 個月相對熱度，並以「焦慮」作為 anchor 將批次結果縮放到同一相對尺。這不是 Google Ads 月搜尋量，不能直接等同每月搜尋次數。
2. YouTube 搜尋：用 Chrome/CDP 讀取 YouTube 搜尋結果頁，抓每個關鍵字 Top 3 影片的公開觀看數、頻道與發布時間。

Google Keyword Planner 的絕對月搜尋量仍需用戶提供 Google Ads 帳號；YouTube Data API v3 也需要 API key，本版改用公開搜尋頁補足可見數據。

Google Trends 欄位定義：

- `Avg`：台灣近 12 個月平均相對熱度，anchor 後的相對值；高於 100 代表該詞在其批次中熱度高於「焦慮」。
- `Peak`：台灣近 12 個月峰值相對熱度；Google Trends 本身為相對指標，不是月搜量。
- 絕對月搜尋量：仍需 Google Ads / Keyword Planner 授權。

| 低搜尋量 | 自我內耗、職場內耗、情緒耗竭、第二大腦、微習慣、人生複利、人生遊戲、資訊焦慮、資訊過載、數位極簡、低能量、設立界線、不知道自己要什麼 | 心靈成長、自我價值、反脆弱、界線感、完美主義、複利 |

### 解讀

真正適合白熊優先打的不是最大詞，而是「中高痛點 + 中低競爭 + 可連回白熊自有方法論」：內耗、想太多、低能量、資訊過載、第二大腦、職場內耗、人生迷惘。

## 3. 推薦白熊優先打的 10 個關鍵字

### 1. 內耗

- 為什麼推：痛點強、台灣中文語境自然、可接心理與生產力。
- EP 標題：`你不是懶，你只是被內耗偷走了人生的電量`
- IG 字卡：`停止內耗的第一步：不要再跟腦內小劇場辯論`
- Threads 開頭：`有一種累，不是事情很多，是你腦中同時開了 40 個分頁。`

### 2. 想太多

- 為什麼推：搜尋大、共鳴高，適合短影音擴散。
- EP 標題：`為什麼你越想清楚，反而越動不了？`
- IG 字卡：`想太多不是聰明，是大腦在過度防禦`
- Threads 開頭：`想太多的人最痛苦的地方，是連休息都像在解題。`

### 3. 低能量

- 為什麼推：競爭低、語感新，能接 EP06 反脆弱躺平術。
- EP 標題：`低能量不是廢，是人生系統在要求降載`
- IG 字卡：`低能量日也能完成的 3 個人生任務`
- Threads 開頭：`如果你今天只剩 20% 電量，請不要用 100% 的標準審判自己。`

### 4. 職場內耗

- 為什麼推：有明確 TA，上班族痛點比泛成長更精準。
- EP 標題：`職場內耗的真相：你不是玻璃心，是系統噪音太多`
- IG 字卡：`上班最累的不是工作，是腦內一直重播那句話`
- Threads 開頭：`很多人下班後還在上班，因為主管的一句話還住在腦子裡。`

### 5. 第二大腦

- 為什麼推：競爭仍可切利基，和 Obsidian/Notion/白熊系統高度 fit。
- EP 標題：`第二大腦不是筆記術，是把內耗搬出腦袋的方法`
- IG 字卡：`你的腦袋不是倉庫，不要把所有人生任務塞進去`
- Threads 開頭：`我做第二大腦不是為了變強，是為了不要每天被自己吵死。`

### 6. 資訊過載

- 為什麼推：可接降噪人生，自有詞能養成品牌。
- EP 標題：`資訊過載時代，真正稀缺的不是知識，是安靜`
- IG 字卡：`不是你不專心，是世界太吵`
- Threads 開頭：`你以為自己在學習，其實只是一直把焦慮加到購物車。`

### 7. 人生迷惘

- 為什麼推：長青痛點，能接人生遊戲/任務卡。
- EP 標題：`人生迷惘時，不要找答案，先重設任務欄`
- IG 字卡：`迷惘不是沒方向，是方向太多沒有排序`
- Threads 開頭：`迷惘的人通常不是沒有選項，而是每個選項都像會失去另一個人生。`

### 8. 微習慣

- 為什麼推：比「原子習慣」競爭低，適合白熊低壓風格。
- EP 標題：`不要再逼自己自律了，先做小到不會失敗的微習慣`
- IG 字卡：`真正能改變人生的，通常小到看起來很可笑`
- Threads 開頭：`如果一個習慣需要靠意志力撐，它大概很快就會倒。`

### 9. 設立界線

- 為什麼推：心理與職場/關係都能打，女性受眾與高敏感受眾適配。
- EP 標題：`不會拒絕的人，最後都會用崩潰替自己設界線`
- IG 字卡：`界線不是冷漠，是不讓自己被用到沒電`
- Threads 開頭：`你以為你是在體貼別人，其實你只是一直背叛自己。`

### 10. 人生複利

- 為什麼推：自有書籍詞，可長期建立品牌資產。
- EP 標題：`人生複利：真正拉開差距的，不是努力，是可重複的小系統`
- IG 字卡：`複利不是每天變強，是每天少一點失控`
- Threads 開頭：`我越來越相信，人生不是靠爆發改變，是靠不會把自己耗乾的小系統。`

## 4. 下一步補數據

1. 用 Google Keyword Planner 設定地區台灣、語言繁中，批次匯出 48 詞絕對月搜尋量與競爭度。
2. 若提供 YouTube Data API v3 key，改用 API 正式抓 `search.list` + `videos.list`，取代目前的公開 SERP 抓取。
3. 每月重跑 `pytrends` 與 YouTube SERP，觀察「內耗 / 低能量 / 資訊過載 / 第二大腦」是否持續上升。
