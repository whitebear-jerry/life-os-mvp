# 多平台週報 2026-WW22

## 0. 執行狀態

v2 已補入 YouTube 公開頁面可見數據：白熊人生攻略頻道、EP1、EP2 的訂閱、觀看、讚與留言狀態。由於目前沒有 YouTube Analytics API / YouTube Data API key，無法取得曝光、CTR、平均觀看時長、觀看時數、留存曲線與訂閱來源。Meta 端仍缺 Threads/IG/FB API 憑證或每週截圖，因此保持待用戶提供資料源。

建議資料來源：

- YouTube：目前已用公開頁面補 `views`、公開讚數與留言狀態；完整週報仍需 YouTube Analytics API 取 `impressions`、`ctr`、`watch_time_minutes`、`average_view_duration_seconds`、`subscribers_gained`。
- Threads：原生 Insights 可看近 90 天 views、interactions、followers；週報最小欄位為 views、likes、replies、reposts、quotes、followers。
- Instagram / Facebook：優先用 Meta Business Suite 匯出或 Graph API；若 API 卡住，先用每週截圖 + OCR 手動錄入。

公式：

- Threads 互動率 = `(likes + replies + reposts + quotes) / views`
- IG 互動率 = `(likes + comments + shares + saves) / reach`
- FB 互動率 = `(reactions + comments + shares) / reach`
- YouTube 訂閱轉換 = `subscribers_gained / views`
- YouTube 觀看品質 = `average_view_duration / video_length`

## 2. 個別平台拆解

### YouTube

本週 YouTube 公開數據已補：頻道 `🎮 白熊人生攻略` 目前 4 位訂閱者；EP1《你大腦現在跑了幾個 App?|大腦 RAM 清倉術》公開 18 次觀看、0 公開讚、0 留言；EP2《為什麼你越「懂事」越累？幫心靈裝一道防火牆》公開 6 次觀看、0 公開讚、0 留言。由於沒有 Analytics API，曝光、CTR、平均觀看時長、觀看時數、前 30 秒留存與訂閱轉換仍無法取得。短期判讀：樣本仍太小，優先改善標題/縮圖/前 5 秒 Hook，並用 Shorts/Threads 導第一波冷啟動流量。

### Threads

Threads 是目前最適合測口語版與內耗題材的地方。每篇至少記錄：發文時間、開頭句、主題、views、likes、replies、reposts、quotes、新追蹤。若互動率高但新追蹤低，代表共鳴夠但個人定位/導流不明；若 views 高但 reply 低，結尾問句要更具體。

### Instagram

IG 建議拆成 Reels、貼文、限動三張表。貼文看儲存與分享，限動看互動貼紙參與率，Reels 看 3 秒/完整觀看與追蹤轉換。白熊若主打字卡，最重要不是按讚，而是儲存與分享。

### Facebook

FB 粉專可作為長文與影片二次分發。建議每週比較「影片 vs 圖文」觸及；若影片 3 秒觀看高但互動低，代表開頭有效但內容沒有引發留言；若圖文觸及低但留言深，適合轉成 Threads 長文。

## 4. 異常警示

| 規則 | 燈號 | 動作 |
|---|---|---|
| 任一平台觸及/觀看較上週下跌 > 30% | 紅 | 檢查發文頻率、主題、平台限流、是否缺互動 |
| 互動率連續 2 週下滑 | 黃 | 重寫 Hook 與結尾問句，降低 AI 腔 |
| 單篇 views/reach 高於近 4 週平均 2 倍 | 綠 | 拆解標題、開頭、主題，複製成 3 篇變體 |
| YouTube CTR < 2% 且曝光足夠 | 紅 | 改標題/縮圖，不先改內容 |
| YouTube 前 30 秒留存 < 50% | 黃 | 重剪開頭，前 5 秒先給結論/衝突 |
| Threads views 高但 replies 低 | 黃 | 結尾改成二選一或具體情境問題 |

## 5. 下週建議

1. YouTube 本週最該打的關鍵字是 `內耗` 與 `低能量`：`內耗` 的 YouTube 搜尋 Top 3 已出現 Dcard、阿滴、天下文化且近期熱，代表題材正在被平台理解；`低能量` 競爭較低，適合白熊建立自有語感。
2. 下週每支長片至少切 3 支 Shorts：Hook 版本 A「你不是懶，是內耗偷電」、版本 B「低能量不是廢，是系統要求降載」、版本 C「別把訪客當 Root 權限」。追蹤 Shorts 導回長片的觀看與訂閱。
3. 先建立 `週報/raw/`，每週放四平台 CSV 或截圖；YouTube 最少要收 `views / likes / comments / subscribers`，若能開 Analytics 再補 `impressions / CTR / avg view duration / retention`。Threads/IG/FB 先用截圖或匯出表，不要等 API 完美才開始記錄。
