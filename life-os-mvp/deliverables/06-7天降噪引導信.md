# 7 天降噪引導信

用途：讀者留下 Email 後，每天寄一封短引導信，幫他從免費贈品走向模板包。

## Day 1｜你不是懶，是大腦 RAM 爆了

主旨：你不是沒有行動力，你只是大腦太吵了

```text
嗨，今天先不用解決整個人生。

請把腦中所有正在吵的事寫下來：
工作、家庭、人際、金錢、健康、未完成的訊息、一直想做卻沒做的事。

你會發現，光是把它們倒出來，大腦就會安靜一點。

今天練習：
打開「人生降噪一頁表」，填第 1 題和第 2 題。

今天的確認句：
我不需要用大腦硬記整個人生。
```

## Day 2｜願望不是許願，是關鍵字設定

主旨：你的大腦每天都在搜尋你最常輸入的關鍵字

```text
如果你每天想的是「我不夠好」，大腦就會幫你找不夠好的證據。
如果你每天問的是「我可以怎麼前進一小步」，大腦就會開始搜尋下一步。

今天練習：
寫下你現在最常輸入給大腦的一句話。
再把它改寫成「我想要什麼」。

例：
我不要再這麼混亂。
改成：
我想要每天有一個清楚的最小行動。
```

## Day 3｜痛苦有時是腦內加戲

主旨：今天只寫事實，不寫劇本

```text
今天請選一件讓你煩的事。

先寫腦中劇本：
「他是不是討厭我？」
「我是不是又搞砸了？」

再寫攝影機事實：
「他今天還沒回訊息。」
「會議中有人提出一個修改意見。」

事實會讓大腦有空間。
劇本會讓大腦越演越累。
```

## Day 4｜你的善良需要權限管理

主旨：不是所有人的情緒，都有權限進入你的系統

```text
今天請列出一個最讓你耗電的人、事或資訊源。

問自己：
我是不是給了它太高的權限？
它真的需要完全存取我的時間和情緒嗎？

今天練習：
把它從「完全存取」調成「部分存取」或「只讀」。

界線不是冷漠。
界線是讓你有能力長期善良。
```

## Day 5｜第二大腦是人生降噪系統

主旨：把一件事交給系統，不要交給焦慮

```text
今天選一件你一直怕忘記的事。

把它放進外部系統：
Obsidian、Notion、備忘錄、行事曆都可以。

重點不是工具多漂亮。
重點是讓大腦知道：這件事已經有地方放了。

今天練習：
放進系統後，寫下一個明確的下一次查看時間。
```

## Day 6｜用一頁儀表板重開機

主旨：今天只問四個問題

```text
今天請填 Life OS 一頁儀表板。

四個問題：
1. 今天最重要的一件事是什麼？
2. 我今天的能量是幾分？
3. 今天要關閉哪一個迴圈？
4. 今天要保護哪一段時間？

這不是待辦清單。
這是幫你把人生重新聚焦。
```

## Day 7｜選一個 45 天合約

主旨：不要靠一時動力，簽一個可執行的小合約

```text
如果這 7 天你有感覺大腦安靜一點，下一步不是做更大的計畫。

下一步是選一個願望，簽下 45 天覺醒合約。

每天只做一個願望關鍵字，一個最小行動。

如果你想要完整模板包，可以從 45 天覺醒合約開始，
或升級成 Life OS 模板全包。
```
