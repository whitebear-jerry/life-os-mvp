# Life OS 營銷 MVP

這是一個最小可執行漏斗，用來驗證「降噪人生 / Life OS」是否能吸引讀者從免費內容走到低價產品。

## 已做出來的 MVP

- `index.html`：互動測驗、漏斗入口、書稿圖片素材與低價產品 CTA。
- `freebie.html`：免費贈品頁，將人生降噪一頁表做成可理解的交付頁。
- `starter.html`：NT$249 入門單品頁，主推 45 天覺醒合約。
- `offer.html`：NT$399 模板全包銷售頁，說明 4 個模組、使用場景與 7 天引導信。
- `product-ladder.html`：產品階梯頁，定義免費、低價、中價、高價路線。
- `content-plan.html`：7 天內容測試頁，整理 Day 1 到 Day 7 的發布方向。
- `templates/`：保留 Markdown 原稿，方便轉 PDF、Notion、Google Form 或 Gumroad 交付物。

## 本地試跑

直接用瀏覽器打開：

```text
life-os-mvp/index.html
```

## 最小驗證指標

- 測驗完成數：50 人
- 免費表下載或索取：30 人
- 低價產品購買：3 到 5 人
- 回饋留言：5 則

## 下一步

1. 選定 Tally 或 Google Form，替換目前的 Email MVP 表單示範。
2. 把 `freebie.html` 或 `人生降噪一頁表.md` 轉成 PDF。
3. 先發布 Day 1 到 Day 3 內容，觀察留言「降噪」「關鍵字」「攝影機」的人數。
4. 有留言後，引導讀者做測驗並留下 Email 領 PDF。
5. 若 3 到 5 人願意小額購買，再把 `starter.html` / `offer.html` 串到正式付款頁。
